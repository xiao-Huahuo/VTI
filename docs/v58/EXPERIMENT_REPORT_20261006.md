## 摘要

本实验研究 agent-memory benchmark 中，原生重置后遗留的状态是否与后续检索的顺序敏感性有关。采用固定四题、12个完整历史顺序、Native Reset（N）与 Verified Cleanup（V）两种策略，执行24条独立 sequence、96个 trial、4392次会话重放。主指标是同一题目和目标位置下，不同完整历史顺序产生的检索表示离散度。

冻结主结果为：S_N=0.863583，S_V=0.727387，Δ=0.136197，12个order block内4096次标签交换的精确单侧p=0.0102539，满足预定Δ>0且p<0.05。V相对N的离散度降低约15.77%。这是固定四题和绑定执行条件下的正结果，说明清理策略降低了完整历史／顺序条件化的检索离散度。

执行后补查的机制记录显示：N条件36次后续trial首次抽取的last_k_messages均非空，V条件对应36次全部为空。它将“状态残留”与“后续抽取输入”连起来，但未量化全部结果差异的中介来源。四题平均差异均为正，12个题目×位置单元中9个为正、3个方向相反；这些是事后描述，不是额外确认性检验。

24条sequence的4584个检查点完整回读通过；96个检索footprint重新计算逐float32元素一致；独立实现重算4096次交换，结果一致。答案与参考答案全部保存，correctness按用户此前决断不评分。本报告不主张准确率、评分或排行榜变化，不主张普遍成立或实现完全trial isolation。

## 一 研究问题与证据定位

项目的核心问题是：benchmark声称case之间独立时，Native Reset能否保证前一trial不会改变后一target的行为？Reset是具体操作，trial isolation是需要验证的性质。

V58检验以下方向性预测：若N条件留下会参与后续抽取的历史状态，则在完整历史顺序变化时，其检索表示平均离散度可能高于V条件。竞争解释包括模型抽取波动、执行环境波动、slot／时间因素、其他未清理状态和测量表示特性。

历史定位：V55已提供固定Redis×Mem0配置的held-out因果E2证据；V56停于clean-clean分叉，V57的LangMem–DeepSeek开发兼容性不通过。V58有自己的冻结设计、run身份与结果，不能自动继承旧版本的结论范围。

本版增加的证据是**清理策略与顺序条件化检索离散度之间的下游差异**。统计门槛通过与机制完全识别是两个验收层次；当前支持前者，并提供后者的过程证据。

## 四 测量与统计方法

### 4.1 原始检索到footprint

每个trial完成全部历史ingestion后，按固定路径调用 `search(question, filters={user_id: scope}, top_k=10)`，保存完整原始Top-10及provider顺序。按冻结V45规则提取文本，使用前五条构建Ordered Top-5 Retrieval Footprint。

文本进行Unicode NFC、换行及空白规范化，保留大小写、标点、重复项与检索顺序。每条文本生成384维L2归一化float32 embedding，rank权重为 `1/log2(r+1)`。五条embedding和五个presence mask组成1925维float32向量；缺位填零，空检索为合法全零表示。完整footprint不再全局归一化。

距离计算将两向量转换为float64，使用Euclidean L2。该指标同时反映文本语义、rank和缺位情况，数值及15.77%的比例都依赖这套冻结表示。

### 4.2 主统计量

对每个target×position（位置2–4）×policy单元，三条对应完整历史顺序的观测构成三对距离，其平均为该单元离散度D。

```text
D(t,p,policy) = [d(v1,v2) + d(v1,v3) + d(v2,v3)] / 3
S_policy     = 12个target×position单元的D的平均
Δ            = S_N − S_V
```

位置1不进入主离散度计算，因为没有前序trial，但其原始检索与答案照常保存。

### 4.3 冻结检验与判定

在每个order block内交换或不交换N/V标签，共 `2^12=4096` 种分配。每一种都重新计算D、S及Δ，使用预先绑定的单侧右尾：

```text
p = count(Δ_perm ≥ Δ_observed − 1e−12) / 4096
通过门槛 = Δ_observed > 0 且 p < 0.05
```

这是冻结block标签交换假设下的精确计算；“精确枚举”不意味着所有可交换性、时间效应或执行噪声假设已被经验排除。没有将96trial或4392次会话当作独立样本增加显著性。

| Policy | Trial阶段 | 核查数 | last_k_messages非空 | 字节范围 |
| --- | --- | ---: | ---: | --- |
| N | 初始trial | 12 | 0 | 0 |
| V | 初始trial | 12 | 0 | 0 |
| N | 后续trial 2至4 | 36 | 36 | 1954至2788 UTF-8字节 |
| V | 后续trial 2至4 | 36 | 0 | 0 |

同时，72个trial边界中，两策略的native vector/backend count均归零；N侧messages保留，V侧归零。

因此，过程证据已经超过“磁盘上存在残留文件”：N条件的残留消息在后续抽取调用中表现为非空last_k_messages，V切断了该已记录的输入路径。它支持如下机制链：

```text
Native Reset后的sidecar消息保留
          → 后续trial抽取的last_k_messages非空
          → memory更新与检索有受先前历史影响的通道
```

最后一箭头的总体下游差异由冻结主结果支持，但本实验没有完成中介效应分解或独立的残留注入／删除对照，不能将Δ全部归给这一条路径，更不能把15.77%当作残留历史的贡献比例。

V条件S_V=0.727387仍明显非零；其余波动可与抽取随机性、运行时状态、未纳入清理边界的因素及检索测量有关。当前未用额外校准实验分离这些来源。

## 十 结果解释与限制

### 10.1 对研究意味着什么

这是支持研究方向的正结果：清理策略的差异已经延伸到后续检索行为，而非停在状态残留检查。主门槛通过、分题平均方向一致及实际抽取上下文的过程记录，构成相互衔接的证据。

效应在冻结指标上的大小可测，但不能仅凭p值称其实际影响巨大；也不能在缺少答案评分时宣称benchmark得分失效。局部三个反向单元和V的非零离散度要求保留克制的结论。

### 10.2 限制与竞争解释

1. **固定四题与单栈**：独立题目数小，不能外推LongMemEval全体或其他后端／模型。
2. **完整历史与相邻前驱**：设计平衡前驱和位置，但未隔离完整历史中的单一因果来源。
3. **执行波动**：temperature=0、top_k=1和固定seed不构成完全确定性证明；V非零离散度表明仍有变异需要解释。
4. **交换检验假设**：4096枚举是精确算术；block标签的可交换性和slot／时间等竞争解释仍是解释条件。
5. **执行修订和恢复**：8192修订发生于失败之后；复用与重跑按完成／基础设施失败判定，原12个block不是全部在一个不中断的执行阶段产生。透明记录降低复现歧义，但不等同于未经改变的原始确认性执行。
6. **指标含义**：footprint混合语义、排序、presence变化；其离散度降低不等于“内容更正确”或“污染少了同等比例”。
7. **机制识别**：last_k路径有直接记录，仍缺独立中介分解，不能宣称唯一机制。
8. **答案效用**：correctness未冻结判分器并依用户决定待定，不能支持accuracy、score或ranking变化。
