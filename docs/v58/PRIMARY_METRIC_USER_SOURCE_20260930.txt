经过与 V55 相同的 `normalize_results` 后，按照 provider 返回的 retrieval 顺序取得 textual memory content。

```text
retrieved memory text
```

- order label

如果这一点无法从冻结 V45 engine 唯一核实，则继续 fail-closed，不自行猜字段。

完整 Top-10 原始 retrieval 必须保存在 raw 中。

footprint 只使用其中前五条。

$$

零范数或非 finite embedding 视为执行错误，不继续计算正式指标。

# 7. Rank weighting

Top-5 的 rank weight 固定为：

$$
w_r=\frac1{\log_2(r+1)},\qquad r=1,\ldots,5
$$

retrieval 顺序保持原样。

不存在任何重新排序。

---

# 8. Missing retrieval 与 presence mask

如果 retrieval 少于五条：

- 已存在的位置使用正常 embedding；
- 缺失位置 embedding 使用 384 维零向量；
- 每一个位置附加 presence mask $m_r$。

定义：

$$
m_r=
\begin{cases}
1,&\text{该 rank 存在 retrieval}\\
0,&\text{否则}
\end{cases}
$$

最终：

$$
v=
[
w_1e_1,\ldots,w_5e_5,
w_1m_1,\ldots,w_5m_5
]
\in\mathbb R^{1925}
$$

footprint 保存为 `float32`。

空 retrieval 是合法科学 outcome：

```text
v = all-zero 1925D footprint
```

不得因为 retrieval 为空而替换 case 或删除 observation。

---

# 9. Primary distance

V58 的 $d$ 唯一固定为：

```text
Euclidean L2 distance
```

计算距离前，将两个 footprint 转为 `float64`：

$$
d(v_a,v_b)
=
\left\|
\operatorname{float64}(v_a)
-
\operatorname{float64}(v_b)
\right\|_2
$$

不得进一步：

- normalize 1925D footprint
- standardize dimensions
- clip
- threshold
- cosine transform
- Jaccard transform
- set matching
- optimal matching
- retrieval-ID matching

V58 primary 只使用上述 Euclidean distance。

其他距离如果未来需要，只能作为明确标记的 post-hoc / secondary analysis，不能改变 V58 primary 判定。

---

# 10. Cell dispersion

原冻结定义保持不变。

对于 target $j$、position $q\in\{2,3,4\}$、policy $p$，exact-cover 给出三个 predecessor-conditioned observations：

$$
v_1,v_2,v_3
$$

定义：

$$
D_{jqp}
=
\frac{
d(v_1,v_2)+
d(v_1,v_3)+
d(v_2,v_3)
}{3}
$$

全部距离计算使用前述 float64 Euclidean distance。

---

# 11. Policy dispersion

保持原定义：

$$
S_p=
\frac1{12}
\sum_{j=1}^{4}
\sum_{q=2}^{4}
D_{jqp}
$$

其中 $p\in\{Native,Verified\}$。

Primary effect：

$$
\Delta
=
S_{Native}-S_{Verified}
$$

$\Delta>0$ 表示 Native 下的 order/history-conditioned retrieval dispersion 更大。

---

# 12. Exact randomization inference

原冻结推断完全不变。

12 个 order block 内分别交换两个独立 sequence 的 N/V label：

$$
2^{12}=4096
$$

必须完整枚举 4096 个合法 assignments。

对于每个 assignment，重新计算完整：

```text
D
→ S_Native
→ S_Verified
→ Delta
```

不得只交换最终汇总数字。

单侧 exact p-value：

$$
p=
\frac{
\#\{
\Delta^{perm}
\ge
\Delta^{obs}-10^{-12}
\}
}{4096}
$$

tie tolerance：

```text
1e-12
```

不得增加 `+1` correction。

不得使用 Monte Carlo permutation。

---

\Delta>0
$$

p<0.05
$$

才允许得出：

- Verified Cleanup universally solves isolation

# 14. 为什么选择这一补充，而不是重新设计指标

本次 amendment 的选择依据必须记录为：

1. V58 正式结果尚未产生，因此没有依据 V58 outcome 选择指标。
2. V57 在本项目中已经前瞻性冻结同一 Ordered Top-5 1925D footprint。
3. V57 已经使用该 footprint 上的 Euclidean norm 进行 primary inference。
4. V59 已批准设计明确写有“仍使用相同 Top-5 retrieval footprint”。
5. 复用已有 measurement definition 比临时选择 cosine、Jaccard 或新的 embedding 表示具有更少研究者自由度。

这些是本次**新决断的依据**。

不得写成：

> V58 原本就已经冻结了 Top-5 Euclidean metric。

原 V58 冻结确实遗漏了这一点。
