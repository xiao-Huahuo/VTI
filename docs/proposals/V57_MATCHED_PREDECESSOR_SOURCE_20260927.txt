# 1. 先修正 V57 真正要估计的量

上一版是：

```text
Control:
fresh → reset-empty → target

Treatment:
fresh → predecessor → native reset → target
```

这有一个隐藏问题：

```text
Control 没跑 predecessor
Treatment 跑了 predecessor
```

因此两边不仅 memory backend 不同，LLM runtime 的热状态、调用历史、系统负载等也不同。

如果再在 reset 后强制 unload：

```text
predecessor
→ reset
→ unload model
→ target
```

又会把真实 benchmark 中可能存在的 runtime carryover 人为去掉。

这两个都不理想。

## 新的实验单元

每个 replicate 都创建：

```text
Fresh LLM runtime

Fresh Backend A
Fresh Backend B
```

两个 backend instance 完全相同。

然后**无论最终分到哪个 arm，都先做完全相同的 full predecessor**：

```text
Backend A
↓
完整 predecessor
52 sessions
↓
完整 predecessor query / answer
```

直到 predecessor 全部完成以后，才执行被冻结的 treatment assignment。

### Native arm

```text
Backend A
已有 predecessor state
↓
stock native reset
↓
同一个 Backend A
↓
完整 target
```

### Pristine-shadow arm

```text
Backend A
已有 predecessor state
↓
丢弃 A

Backend B
从未接触 predecessor
↓
stock native reset on empty state
↓
Backend B
↓
完整 target
```

也就是：

$$
Y(1)=
\text{Target after native reset of predecessor-bearing backend}
$$

$$
Y(0)=
\text{Target on pristine backend after the same predecessor workload}
$$

两边：

```text
predecessor LLM calls
answerer warm state
运行时间级别
模型 runtime history
```

都是匹配的。

唯一主要区别是：

> target 使用的 memory backend 是否经历过 predecessor 后再 native reset。

这才真正把问题锁定在：

# Native reset 是否恢复到了 pristine-equivalent memory state？

# 4. 这也解决 exact randomization 的 interference 问题

现在一个 statistical unit 是：

$$
u=(backend,target,replicate)
$$

每个 unit 拥有自己的：

```text
memory backend
database
LLM server
process state
namespace
```

unit $u$ 的 treatment 不可能通过 backend/runtime 影响 unit $u+1$。

因此可以真正定义潜在结果：

$$
Y_u(1),Y_u(0)
$$

其中 assignment：

$$
A_u\in\{0,1\}
$$

在任何 target outcome 产生前随机确定。

而且为了更严谨：

> runner 在 predecessor 完成以前不读取该 unit 的 assignment。

也就是：

```text
full predecessor
↓
checkpoint predecessor-complete
↓
读取 frozen assignment
↓
native / shadow
```

这样 assignment 连 predecessor path 都不可能影响。

# 5. Fisher randomization test 不再解释成“同分布检验”

你指出这一点也非常关键。

新的 primary statistical claim 不写：

> clean 和 native 来自不同 stochastic distributions。

而是明确写成 randomized experiment 的：

## Sharp causal null

对该 target 的 10 个 experimental units：

$$
H_0:
Y_u(1)=Y_u(0)
\quad
\forall u
$$

5 个 unit 随机进入 native，5 个进入 pristine-shadow。

因此：

$$
\binom{10}{5}=252
$$

个合法 assignment。

在：

- assignment 真随机；
- unit 之间没有 interference；
- outcome 定义固定；

的条件下，Fisher exact randomization test 的有限样本 Type-I error 来自**随机化机制本身**。

不需要：

```text
clean max radius
Gaussian assumption
normality
exchangeable stochastic trajectories
```

甚至 slot 随时间有 baseline drift 也不自动破坏 Fisher test，因为 slot-specific potential outcomes 可以不同；关键是 assignment 真随机且一个 unit 的 assignment 不改变另一个 unit 的 outcome。

# 6. 删除上一版 16,003,008 个 global assignment 的设计

这一步也应该重新改。

你指出：

> global mean statistic 可以因为一个 target 特别强而阳性。

完全正确。

而我们的真正目标其实不是：

> 三个 target 里至少一个有 effect。

我们需要的是：

> **一个独立 backend 上 effect 能否跨 target 重复。**

因此新的 backend-level primary claim 直接改成：

# Partial Conjunction Test

三个 target 分别计算 exact randomization p-value：

$$
p_1,p_2,p_3
$$

排序：

$$
p_{(1)}
\le
p_{(2)}
\le
p_{(3)}
$$

我们要检验：

> 至少两个 target 存在 effect。

使用预先冻结的 Bonferroni partial-conjunction：

$$
p_{PC,2/3}
=
\min(1,2p_{(2)})
$$

它检验的 null 是：

> 三个 target 中最多只有一个存在 effect。

因此，一个 backend 只有：

$$
p_{PC,2/3}<\alpha_B
$$

才能得到：

```text
REPLICATED_RETRIEVAL_INFLUENCE
```

这比上一版的 global mean 更符合论文需要。

# 9. Retrieval footprint 的精确定义

provider 仍然按照 benchmark 配置执行正常的：

```text
Top-10 retrieval
```

**不改变 query limit。**

Primary measurement 只读取其中前 5 条。

对每个 retrieval text：

1. Unicode NFC；
2. `\r\n → \n`；
3. 前后 trim；
4. 连续 whitespace collapse 为一个空格；
5. 不 lowercase；
6. 不删 punctuation；
7. duplicate 保留，因为 duplicate retrieval 本身也是行为。

用冻结的：

```text
BAAI/bge-small-en-v1.5
```

产生 L2-normalized `float32` embedding：

$$
e_r\in\mathbb R^{384}
$$

缺失 rank：

$$
e_r=0
$$

另外：

$$
m_r=
\begin{cases}
1 & rank\ r\ exists\\
0 & otherwise
\end{cases}
$$

固定 DCG weights：

$$
w_r=\frac1{\log_2(r+1)}
$$

最终 trajectory footprint：

$$
v=
[
w_1e_1,
w_2e_2,
\ldots,
w_5e_5,
w_1m_1,\ldots,w_5m_5
]
$$

因此：

$$
v\in\mathbb R^{1925}
$$

这比上一版的 weighted average 更好，因为不会出现：

```text
两个完全不同的 retrieval list
刚好平均到相似向量
```

它同时保留：

- 内容；
- rank；
- retrieval count；
- duplicates。

# 10. Primary target statistic

对 5 native + 5 pristine footprints 使用固定 Euclidean energy statistic：

$$
T=
\frac{2}{nm}
\sum_{i,j}
\|v_i^{N}-v_j^{C}\|_2
-
\frac1{n^2}
\sum_{i,i'}
\|v_i^{N}-v_{i'}^{N}\|_2
-
\frac1{m^2}
\sum_{j,j'}
\|v_j^{C}-v_{j'}^{C}\|_2
$$

其中：

$$
n=m=5
$$

然后穷举全部 252 个合法 5/5 assignments：

$$
p_j
=
\frac{
\#\{a:T_j(a)\ge T_j^{obs}\}
}{
252
}
$$

ties 使用固定：

```text
T_perm >= T_obs - 1e-12
```

所有 footprint 先存盘并 SHA256；统计统一用 `float64`。

不存在 bandwidth、learned threshold 或 clean radius。
